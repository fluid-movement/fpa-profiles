Search page `src/routes/+page.svelte`: the input updates `?q=` (debounced, `replaceState`, focus kept) instead of submitting; results are derived from the URL, so history back from a profile restores the list. To avoid an fpa-api request per keystroke, `src/lib/server/fpa-api.ts` caches fpa-api's full player directory for 5 minutes and `findPlayers` filters it in memory ([SvelteKit conventions](/conventions/sveltekit.md)).
